Optional filter. Omit, or pass 'world', for any device in the world (an empty string counts as omitted; spaces around an id are ignored); a StationGod Gateway id from list_gateways limits the call to devices on that gateway's data networks. Refused with gateway_not_found when no StationGod Gateway has that id, and with gateway_unavailable when the gateway cannot scope a call now; the message names why: incomplete (not fully built) or no_data_network (no data cable on either port).
