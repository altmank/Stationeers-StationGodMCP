What each Ingot Vault stores, and every Remote Vault's link.
Options:
- id (string or array): One Ingot or Remote Vault; default every vault.
Any what that takes an id takes a list: one row per id, {results: [{index, ok, reference_id, payload | error}], count, success_count, error_count}, payload the one-id reply; a bad id is a row with error.
Reply: vaults [{vault, position, on_off, powered, stock, pending_vends}], remote_vaults [{remote, vault_id, connection}], count
Example: inspect {what: "vault"}
