What each Ingot Vault stores, and every Remote Vault's link.
Options:
- id (string or array): One Ingot or Remote Vault; default every vault.
Any what that takes an id takes a list: one row per id, {results: [{index, ok, reference_id, ...} or {index, ok, reference_id, error}], count, success_count, error_count}; a bad id is a row with error.
Reply: vaults [{vault, position, on_off, powered, stock, pending_vends}], remote_vaults [{remote, vault_id, connection}]
Example: inspect {what: "vault"}
