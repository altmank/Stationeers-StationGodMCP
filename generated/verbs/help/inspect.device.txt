A device: logic types it reads and writes, writable ones by name, rocket, umbilical and uplink details.
Options:
- id (string or array, required): Target: an id, a list of ids, a ref ("r3": the ids that reply showed; "r3.rockets.parts"), or "looking_at" (the thing the crosshair is on); "player" where the what says.
- gateway (string, default world): "world" (default) or a gateway id: only devices on its data networks.
- include (list of logic_types): logic_types: every logic type with id and access.
id may be a list or a ref: the reply is {results: [{index, ok, reference_id, payload | error}], count, success_count, error_count}, payload one reply; fields name its keys.
Any what that takes an id takes a list: one row per id, {results: [{index, ok, reference_id, payload | error}], count, success_count, error_count}, payload the one-id reply; a bad id is a row with error.
Reply: device {reference_id, prefab_name, prefab_hash, display_name, runtime_type, slot_count, is_gateway, worn_by, worn_slot}, build_state {current, last, complete, next}, rocket {network_id, name, state, dry_mass_kg, hull_pieces, internals}, umbilical {role, open, partner, partner_distance, search}, uplink {downlink, connected, choices}, logic_types [{id, name, readable, writable}], logic_type_count, writable
Example: inspect {what: "device", id: "4820585"}
