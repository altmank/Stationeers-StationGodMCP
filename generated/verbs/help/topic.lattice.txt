Lattice's whole contract as JSON: find lattice {ask, args} reads, write lattice {command} changes ghosts and plans (a report of Lattice's preview until confirm), show lattice draws on this seat only. show ghost and find ghost stay the short way for build ghosts.
Values: a union is its case's name or an object with that one key ({"ids": [1, 2]}). Cells and offsets are metres [x, y, z] (a piece's centre, as find ghost gives position); turns are rotation degrees [x, y, z] in quarter turns (or Lattice's index 0-23); pieces and kits are prefab names (or hashes); structures are reference ids; keys are "owner/name" (Lattice's own bare: colours planned next waits fail warn remove stale draft select, icons fails warns remove swap finish stale waiting paused, materials ghost solid wire edge see-through glow label faded, families cable pipe chute frame wall window device other, sets selected hovered); colours [r, g, b(, a)] 0-1 or "#rrggbb(aa)". A bare name for an attachment, maker or code is StationGod's (stationgod/<name>).
