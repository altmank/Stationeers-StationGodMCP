A refusal is {code, message, fix}: message says what went wrong, fix what to do next; a fix never names an allow value. Missing or wrong options are one invalid_argument listing every problem: {code, message, problems: [{path, problem}], valid: [this what's own options, the nearest 3 first]}. write logic with no target is missing_target, naming id and writes. Every message uses verb names. game_unavailable: the MCP server could not reach the game; a write may have run if the game took the call.
