Sell to the landed trader as the trade window's Sell does.
Reports first; confirm: true does it.
Options:
- id (string or array, required): The trader contact. A list is one row per id; a contact that is not landed answers an error row, and the others still trade.
- card (string): The credit card paid into; default the one the player carries.
- items (list, required): Up to 32 lines {name or prefab, quantity}.
- confirm (boolean, default false): true acts; false only reports, whatever the call names (typed ids included). Left out, the write rule decides: typed ids act at once where the verb acts on them; a ref, network or spread reports.
Any what that takes an id takes a list: one row per id, {results: [{index, ok, reference_id, payload | error}], count, success_count, error_count}, payload the one-id reply; a bad id is a row with error.
Reply: (Trade) reference_id, name, credit_card_id, credits_before, credits_after, results [{index, ok, name, prefab_name, quantity, credits, error, ok, name, prefab_name, gas, quantity, credits_each, credits_spent, credits_earned, stock_after, wanted_after, ok, error}], count, success_count, error_count, delivered [{reference_id, slot, item, quantity}], gas_atmosphere_id | (BatchResult) results [{index, ok, reference_id, name, credit_card_id, credits_before, credits_after, results, count, success_count, error_count, delivered, gas_atmosphere_id, ok, reference_id, error}], count, success_count, error_count | (TradeReport) reference_id, name, credit_card_id, credits_before, credits_after, results [{index, ok, name, prefab_name, quantity, credits, error, ok, name, prefab_name, gas, quantity, credits_each, credits_spent, credits_earned, stock_after, wanted_after, ok, error}], count, success_count, error_count, delivered [{reference_id, slot, item, quantity}], gas_atmosphere_id, report_only, targets [{id, cell, name, current, new, undo, passed, driven_by, text}], problems [{index, reference_id, code, message, data}] | (TradesReport) trades [{reference_id, name, credit_card_id, credits_before, credits_after, results, count, success_count, error_count, delivered, gas_atmosphere_id}], report_only, targets [{id, cell, name, current, new, undo, passed, driven_by, text}], problems [{index, reference_id, code, message, data}]
Example: trade {what: "sell", id: "7", items: [{prefab: "ItemGoldIngot", quantity: 20}]}
