Built structures by id (up to 256, one job), taken apart; every build state is refunded down to the kit.
Reports first; confirm: true does it.
Options:
- id (string or array, required): The structures.
- allow (list of contents | breach | broken | burst | unsupported): contents: items drop, gas goes; breach: joins spaces 1 kPa or more apart; broken: nothing back; burst; unsupported.
- refund_to (string or integer or array, default [inventory, source, storage, ground]): Where removed materials go: a word (inventory, source, storage, ground, none), a container id, or a list tried in turn. Left out with no player and no materials: none.
- materials (string): The one holder for source and storage refunds: an id or "player". Default the player.
- gas_to (string): Keep a removed device's gas: connected, or a pipe network id.
- include (list of notes): Parts to add to the reply.
- verbose (boolean, default false): Dry run: each port a split cuts; real run: the whole job.
- acknowledge_gas_lost (string): The job id whose gas loss you accept (with the user's agreement); lifts the gas hold.
- confirm (boolean, default false): true acts; false only reports, whatever the call names (typed ids included). Left out, the write rule decides: typed ids act at once where the verb acts on them; a ref, network or spread reports.
- queue (boolean, default true): Wait in line behind a running job (up to 8) instead of answering busy.
- max_wait (number, default 30): Seconds to wait for a confirmed job to finish before answering; 0 answers with its job id at once.
Any what that takes an id takes a list: one row per id, {results: [{index, ok, reference_id, payload | error}], count, success_count, error_count}, payload the one-id reply; a bad id is a row with error.
Reply: (JobQueued) a JobQueued (help {topic: "types", subtopic: "JobQueued"}) | (BuildJob) a BuildJob (help {topic: "types", subtopic: "BuildJob"}) | (RemoveReport) ready, problems [{code, message, index, reference_id}], warnings [{code, message, index, reference_id}], removals [{index, reference_id, prefab_name, display_name, position, build_state, kind, refund}], refund [{prefab_name, quantity}], refund_to, refund_plan, from {reference_id, prefab_name, display_name}, will_burst [{network_id, networks_left, volume_left_l, pressure_now_kpa, pressure_after_kpa, rating_kpa, pipes, where, holds_mol, released_mol, gases}], notes | (RunJob) a RunJob (help {topic: "types", subtopic: "RunJob"}) | (JobBusy) a JobBusy (help {topic: "types", subtopic: "JobBusy"}) | (JobDropped) a JobDropped (help {topic: "types", subtopic: "JobDropped"})
Example: remove {what: "structure", id: ["1559707"], confirm: true}
