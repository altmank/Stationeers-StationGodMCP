- info: the running mod: version, per-method calls and times, game members, its cost to the game
- profiling: profile StationGod's main-thread cost: on, off, reset, report
- console: the latest in-game console lines, oldest first
- command: run any console command and answer what it printed: spawn, delete, teleport, storms, settings (cheat)
- stop: stop a script run or a job; with no id, every live run of this session. The worker is killed 5 s after the stop (longer while an sg call is in flight, never past 30 s), or on a second stop. A running job is allowed to settle
