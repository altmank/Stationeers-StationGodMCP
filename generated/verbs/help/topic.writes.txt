build, swap, remove, trade buy and sell, undo, and every cheat only report until confirm: true. move item by typed ids acts at once (a merge into another stack is [cannot undo]). A write given ids you typed out acts at once; a write whose targets you did not type out (a ref, a network, a spread) reports until confirm: true, listing every target with its current value under targets. confirm: false only reports, whatever the call names (typed ids included); left out, the rules above decide. Every report, direct or scripted, carries report_only: true. A report is never cut; its problems, warnings, will_burst, gas_check, passed and targets stay whatever fields or omit say. A report too large for the client answers report_too_large with the target count and how to narrow it.
Bulk work goes in one call, as wide as its options allow: the call's own schema bounds each list (placements 64, paint items 256, label labels 64, logic writes 256, memory values 512, remove cells and waypoints 1024) and a list over its bound is refused as invalid_argument; nothing is split. A confirmed bulk write is undone as write-N.
Jobs (build, swap, remove, undo) run one at a time; queue (default true) waits in line. A confirmed job, or gas move, answers when it is done, up to max_wait seconds (default 30, at most your client's timeout), with held_ms (how long it paused the game); after that it answers its id: inspect {what: "job", id}. Nothing fills in a default for you.
Undo: undo {id} takes back a build or removal job; swap jobs cannot be undone. A bulk write's undo takes back the steps marked [undo] in its report, newest first, one step at a time; it stops at a refused step, and from_step goes on.
Cheats change the world as a player cannot: move gas and player, write memory, battery and genes, server command (read-only commands too), build blueprint, free: true, force: true. Ask the user before each.
allow: [names] lifts a named guard for this call: door_keepout, split, contents, breach, broken, burst, unsupported, in_use, ground, off_network, out_of_range, overwrite, pad, lint. A call that lifted a guard lists the codes it passed in passed. A build that pays from the player's inventory warns materials_from_player. A write or report on a device that a chip, logic writer, screen script or another run drives warns driven_by (inspect controllers). A write that turns on or opens a vent, valve or pump is refused on a network lint problem unless allow: ["lint"].
