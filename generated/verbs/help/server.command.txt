Run any console command and answer what it printed: spawn, delete, teleport, storms, settings.
Reports first; confirm: true does it.
Cheat.
Options:
- command (string, required): The whole command line.
- lines (integer, default 100): Most lines returned (the oldest kept).
- confirm (boolean, default false): true acts; false only reports, whatever the call names (typed ids included). Left out, the write rule decides: typed ids act at once where the verb acts on them; a ref, network or spread reports.
Read-only commands (help, rocket print) also need confirm: true; the game does not mark which commands change nothing.
The stationgod command (the cheat switch) is refused as console_only: only someone typing at the game's console runs it.
Reply: command, command_key, scope, help_text, arguments, run_simulation, console_available, completes_asynchronously, output_complete, output_line_count, concurrent_log_lines, output [{time, level, text}], note
Example: server {what: "command", command: "help", confirm: true}
