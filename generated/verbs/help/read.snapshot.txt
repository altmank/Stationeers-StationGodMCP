Every readable logic value of matching devices, in one frame.
Options:
- id (string or array): Only these devices.
- prefab (string or integer or array): Prefab: a whole name, a hash, or parts with * ('*Battery*', '*Tank*Insulated*': each part, any order); or a list of them.
- name (string): Part of the shown name or label, any case.
- logic (list): Logic types; left out, every one.
- gateway (string, default world): "world" (default) or a gateway id: only devices on its data networks.
- include (list of zero_ratios): zero_ratios: keep gas and liquid ratios reading 0.
- limit (integer, default 2): Devices returned.
Any what that takes an id takes a list: one row per id, {results: [{index, ok, reference_id, payload | error}], count, success_count, error_count}, payload the one-id reply; a bad id is a row with error.
Reply: gateway_id, devices [{device, logic_values, logic_value_count, zero_ratios_omitted}], count, matched_count
Example: read {what: "snapshot", prefab: "StructureBatteryLarge", limit: 10}
